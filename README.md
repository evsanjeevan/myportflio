# EV Sanjeevan — Portfolio & Developer Hub

Welcome to the repository for my personal portfolio web application! This project serves as my digital home, showcasing my journey, technical expertise, projects, and developer notes.

---

## 🌟 Features & Highlights

*   **Dynamic Content Integration:** Real-time data fetching for projects and technical blogs powered by **Firebase Firestore**.
*   **Custom SPA Routing:** Seamless view switching for project details and markdown blog articles without full page reloads.
*   **Theme Customization:** Automatic system preference detection with a manual dark/light mode toggle saved in `localStorage`.
*   **Interactive Code Blocks:** Built-in syntax highlighting (Prism.js) with a one-click copy-to-clipboard utility.
*   **Fully Responsive:** Designed with **Tailwind CSS** to ensure a fluid experience across mobile devices, tablets, and desktops.

---

## 🛠️ Built With

*   **Frontend:** HTML5, Tailwind CSS
*   **Scripting:** Vanilla JavaScript (ES6 Modules)
*   **Database:** Firebase v10 (Firestore)
*   **Utilities:** Marked.js, DOMPurify, FontAwesome, Google Fonts (Montserrat, Fira Code)
